# Priyani Gulgulia — Portfolio

A single-page portfolio built with React + Vite, generated from the résumé content.

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

Output goes to `dist/`, which you can deploy to Vercel, Netlify, GitHub Pages, etc.
